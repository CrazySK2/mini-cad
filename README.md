# 미니캐드 (Mini CAD)

브라우저에서 바로 쓰는 간단한 2D CAD입니다. 설치 없이 `index.html` 하나로 동작합니다.

- 그리기: 선, 폴리선, 원, 호, 타원, 직사각형, 다각형, 해치, 문자, 치수
- 수정: 이동, 복사, 회전, 대칭, 축척, 간격띄우기, 자르기, 연장, 모깎기, 모따기 등
- 동적 입력: 커서 옆 입력칸에 길이 입력 → Tab → 각도 → Enter
- 3면도 → 3D: 정면도·평면도·우측면도(3각법)를 선택하고 `3D` 명령, STL 내보내기
- DXF / SVG / PNG 내보내기, DXF 가져오기
- 태블릿 지원: 펜, 터치(두 손가락 확대·이동), 블루투스 키보드·마우스

명령 목록은 프로그램 안에서 F1.
